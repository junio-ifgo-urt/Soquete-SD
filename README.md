# Exemplos de Sistemas Distribuídos

Repositório destinado aos exemplos práticos de Sockets

## 🚀 Tecnologias
* Java 17+
* Sockets TCP/UDP
* VS Code

## 📁 Estrutura do Projeto
* **TCP**: Servidor e Cliente de relógio com conexão persistente.
* **UDP**: Comunicação via Datagramas (sem conexão).
* **InetAddress**: Exemplos de resolução de DNS.
